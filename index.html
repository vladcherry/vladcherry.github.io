    How installing works

    Android & desktop Chrome

    Open an app, then use the install icon in the address bar, or the browser menu → Install app. It lands on your home screen or desktop like any other app.

    iPhone & iPad

    Open an app in Safari, tap Share, then Add to Home Screen. Chrome and Firefox on iOS cannot do this — it has to be Safari.

    Why install from each app?

    A browser installs the page you are standing on, so every app is installed from its own page. This store cannot install them for you — the Install button here installs the store itself, as a launcher.
